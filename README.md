## Project Overview

This project analyzes key economic indicators across established and emerging markets to evaluate global competitiveness and identify structural drivers of growth. 

Using Python for data processing and Tableau for visualization, the analysis highlights differences in economic stability, growth potential, and investment attractiveness between the two groups.

## Key Research Focus


• Global economic dominance patterns
• Fastest growing emerging economies
• Relationship between population growth and economic growth
• Which emerging economy is positioned for sustainable long-term growth?  

## Tools & Technologies

- Python (Pandas)
- Tableau
- Excel


## Dataset

Data sourced from publicly available datasets (World Bank / IMF), including:

- GDP growth
- Educational index
- Urbanization levels
- Population
- Manufacturing output levels


## Process

1. Data collection and cleaning using Python  
2. Exploratory data analysis (EDA)  
3. Identification of key indicators  
4. Data visualization in Tableau  
5. Interpretation of results




## Key Insights

- Some merging economies show higher GDP growth but also higher volatility  
- Established economies demonstrate greater economic stability  
- Established tend to pay more attention to education and investing in the future
- Population growth 


## Outcome

- This analysis highlights the trade-off between growth potential and economic stability, showing that sustainable development depends on a balanced mix of education investment, industrial output, and demographic structure.
